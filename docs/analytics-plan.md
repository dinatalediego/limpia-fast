# Analytics Plan — LimpiaFast

## Funnel web

`session → engaged_visit → form_started → form_submitted → whatsapp_photo_click → quote → booking`

## Dimensiones obligatorias

- source / medium / campaign / content / term
- landing_page
- service_type
- district
- urgency
- device (analytics)

## North Star heredada del Growth OS

La landing no se optimiza por CTR ni por submit aislado. Se optimiza por **CAC por reserva y margen posterior a marketing**.

## Primeros experimentos

1. Hero “renovación” vs “rescate”.
2. CTA “Cotizar en la web” vs “Envía una foto”.
3. Formulario en hero vs primer CTA con scroll al formulario.
4. Mostrar precio referencial solo cuando exista evidencia propia suficiente.
5. Añadir galería before/after cuando existan fotos reales etiquetadas por servicio.
